# First Bank Investments – Backend

This repository contains the **backend** for the First Bank Investments application. It provides the core logic for user authentication, bank registration, stock allocation, and portfolio management.

The backend simulates real-world banking and investment behavior, ensuring consistency, security, and scalability.

## Features
- User authentication and authorization
- Bank registration and stock allocation logic
- Portfolio and investment management
- Virtual card management
- Secure data handling and persistence
- RESTful API architecture

## Tech Stack
- **Python**
- **Django** – Backend framework
- **Django REST Framework** – API development
- **JWT Authentication** – Secure access
- **PostgreSQL / SQLite** (depending on environment)

## Core Responsibilities
- Allocate stocks based on selected bank
- Manage user portfolios and balances
- Handle authentication and permissions
- Serve investment data to the frontend
- Maintain virtual card data and transactions

## Getting Started

### Prerequisites
- Python 3.10+
- pip
- Virtual environment (recommended)

### Installation

pip install -r requirements.txt
