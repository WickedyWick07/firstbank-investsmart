# First Bank Investments – Frontend

First Bank Investments is a banking and investment simulation application that allows users to register with a virtual bank and automatically receive the same stock allocations as that bank. The platform provides an intuitive interface for tracking investments, managing virtual cards, and monitoring portfolio performance.

This repository contains the **frontend** of the application, focused on delivering a modern, responsive, and user-friendly banking experience.

## Features
- User authentication and secure login
- Bank registration with automatic stock allocation
- Real-time investment and portfolio tracking
- Virtual banking cards for simulated transactions
- Interactive dashboards and charts
- Responsive design for desktop and mobile
